## Qué es este servicio

[NOMBRE DEL PRODUCTO] es una colección de minijuegos de entrenamiento
cognitivo, jugable sin necesidad de cuenta. Crear una cuenta es
opcional y solo habilita: elegir un nombre de usuario único y aparecer
en un scoreboard global comparando tu mejor puntaje en cada módulo
contra el de otros jugadores.

**Sistemas v3.0.0:**
- Sistema de gamificación con puntos globales, niveles y misiones semanales
- Sistema de badges/insignias con rarezas y categorías
- Sistema de logros secuenciales con cadenas de desbloqueo
- Sistema de notificaciones toast para feedback en tiempo real
- Sistema de transiciones mejorado para navegación fluida
- Sistema de efectos de sonido sintéticos
- Sistema de accesibilidad mejorado con soporte para lectores de pantalla
- Sistema PWA con push notifications, background sync y modo offline
- Sistema de skeleton loading para optimización de carga
